# Checkout demo desde una app vacía

Usa la skill PagosCR incluida en vendor/pagoscr/skills/pagoscr para agregar a esta app un cobro demo por el producto kit-builder. El catálogo del servidor contiene el precio en texto. Crea una orden pendiente, confirma con una notificación firmada y demuestra el estado succeeded consultado desde el almacén. El navegador solo selecciona el producto. Deja un comando npm test reproducible que cubra éxito y monto enviado por un cliente malicioso. No uses red ni credenciales. Explica el límite del almacenamiento elegido.

Trabaja solo en este repositorio. No instales skills/plugins ni modifiques vendor o fixtures.
No leas entornos o credenciales del equipo. No hagas commits en el repositorio de PagosCR.
Informa archivos cambiados, pruebas ejecutadas y qué pago terminó confirmado.
